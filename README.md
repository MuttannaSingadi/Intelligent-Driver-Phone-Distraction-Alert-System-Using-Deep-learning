# 🚗 Intelligent Driver Phone Distraction Alert System

A deep learning project that uses **VGG16 for image classification** and **YOLOv8 for real-time object detection** to identify driver phone distraction and generate instant alerts for improved driving safety.

The system monitors the driver through a camera feed and triggers an alarm whenever unsafe mobile phone usage or drowsiness is detected.

---

## 🚀 Features

- Real-time driver monitoring  
- Phone usage detection  
- Drowsiness detection  
- Instant audio alert system  
- Deep learning–based predictions  
- Live video processing  
- Web interface using Flask  

---

## 🧠 AI Models Used

- **VGG16** → Image classification  
- **YOLOv8** → Object detection  
- Haar Cascade → Face / eye detection
